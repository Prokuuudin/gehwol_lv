# SEO проекта

Основной адрес: https://gehwol.lv. Он задаётся в `seo.config.json`; переменная `SITE_URL` позволяет переопределить его для другой установки.

## Сборка и проверка

```powershell
npx gulp build:docs
php php/bin/render-all.php build/check
node scripts/check-seo.js build/check docs
```

`build:docs` обновляет статические страницы, robots.txt, CSS и шаблоны в `php/templates/` без удаления каталога docs и без запуска сервера. `render-all` выводит все страницы так, как их получит посетитель, и проверка идёт по ним.

Товары, категории, новости, статьи, главная и sitemap.xml формируются PHP (`php/site.php`) из `php/data/*.json` при каждом запросе, поэтому материалы из админки появляются сразу, без сборки. SEO-теги этих страниц строит `php/includes/render.php` по тем же правилам, что `gulp/seo.js` для статических страниц. Главная и страницы категорий собираются gulp как шаблоны: SEO-обработка применяется к ним при сборке, PHP подставляет только списки.

Короткие описания категорий находятся в `src/seo/content.json`. Тексты товаров, новостей и статей хранятся в `php/data/*.json` и редактируются в админке. Изображения получают реальные размеры из исходных PNG/JPEG. Первый кадр товара и изображение hero загружаются сразу; остальные — с lazy loading.

JSON-LD описывает организацию, сайт, страницы и хлебные крошки; новости и статьи дополнительно размечены как Article (заголовок, даты публикации и изменения, изображение, организация как автор и издатель). Разметка Product не используется: у каталога нет цен, а Google требует для Product цену, отзывы или рейтинг и показывал бы такие страницы как ошибочные.

## После публикации

1. Настройте на хостинге постоянные редиректы HTTP → HTTPS, www.gehwol.lv → gehwol.lv и /index.html → /. Сохраняйте путь и параметры URL; исключите циклы редиректов. Серверная конфигурация зависит от Apache/Nginx/CDN и в проекте не представлена.
2. Проверьте, что публичные страницы, sitemap.xml и robots.txt возвращают HTTP 200, а несуществующие страницы — 404. Публикуйте содержимое docs в корень домена.
3. Включите сжатие Brotli/Gzip и кеширование статических ресурсов на хостинге. Перед длительным кешированием CSS/JS настройте версионирование имён файлов или сброс кеша при обновлении.
4. Подтвердите домен в Google Search Console и отправьте https://gehwol.lv/sitemap.xml. Для подтверждения нужен доступ к аккаунту и DNS либо хостингу.
5. Проверьте главную, категорию, товар и статью в URL Inspection и Rich Results Test. Измерьте мобильные Core Web Vitals после публикации.

Административные HTML-страницы отмечены noindex. Это правило индексации, а не защита доступа: административный раздел и файлы данных должны быть защищены средствами приложения и хостинга.

Рекомендации Google: [canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).
