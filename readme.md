# Gulp сборка для верстки сайтов от [ВебКадеми](https://webcademy.ru)

- HTML,
- SCSS,
- Gulp,
- JS

Документация и примеры использования внутри.

Установить зависимости:
```
npm i
```

Зпустить в режиме разработки:
```
gulp
```

Собрать версию для публикации:
```
gulp docs
```

[Смотреть демо](https://user.github.io/repo/)

## Rezerves kopijas / Резервные копии

- Каждое сохранение в админке сначала копирует прежнюю версию JSON в `php/data/backups/<коллекция>-<дата>.json`; хранятся 20 последних на коллекцию.
- Список и восстановление (CLI на сервере или локально):
  ```
  php php/bin/restore.php products
  php php/bin/restore.php products products-20260929-135012-123456.json
  ```
  Текущая версия перед восстановлением тоже сохраняется в backups.
- Полная копия сайта (JSON + загруженные изображения) — скачать по FTP каталоги `php/data/` и `uploads/` целиком. Делать перед каждым деплоем и раз в месяц.
- Битый JSON админка не перезаписывает: показывает ошибку, подробности пишутся в лог PHP сервера.
