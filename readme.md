# Gulp сборка для верстки сайтов от [ВебКадеми](https://webcademy.ru)

- HTML,
- SCSS,
- Gulp,
- JS

Документация и примеры использования внутри.

Установить зависимости:
```
npm i
```

Зпустить в режиме разработки:
```
gulp
```

Собрать версию для публикации:
```
gulp docs
```

[Смотреть демо](https://user.github.io/repo/)

## Rezerves kopijas / Резервные копии

- Каждое сохранение в админке сначала копирует прежнюю версию JSON в `php/data/backups/<коллекция>-<дата>.json`; хранятся 20 последних на коллекцию.
- Список и восстановление (CLI на сервере или локально):
  ```
  php php/bin/restore.php products
  php php/bin/restore.php products products-20260929-135012-123456.json
  ```
  Текущая версия перед восстановлением тоже сохраняется в backups.
- Полная копия сайта (JSON + загруженные изображения) — скачать по FTP каталоги `php/data/` и `uploads/` целиком. Делать перед каждым деплоем и раз в месяц.
- Битый JSON админка не перезаписывает: показывает ошибку, подробности пишутся в лог PHP сервера.

## Как устроен сайт

- Статика (CSS, JS, изображения, юридические страницы, robots.txt) собирается gulp в `docs/`: `npx gulp build:docs` (быстро, без изображений) или `npx gulp docs` (полная сборка).
- Товары, категории, новости, статьи, главная, sitemap.xml и страница 404 формируются PHP (`php/site.php`) из `php/data/*.json` при каждом запросе. Опубликованное в админке видно сразу, сборка не нужна.
- Главная, страницы категорий и общая оболочка страницы — шаблоны в `php/templates/`, их создаёт `gulp build:docs`. После правок в `src/html` пересоберите и закоммитьте `php/templates/`.
- Адреса прежние: `produkts-N.html`, `jaunums-N.html`, `raksts-N.html`, `<категория>.html`. На Apache маршрутизацию делает `docs/.htaccess` (исходник `src/.htaccess`).

Локальный просмотр вместе с админкой:
```
npx gulp build:docs
php -S 127.0.0.1:8010 php/bin/dev-router.php
```
Проверка SEO и ссылок:
```
php php/bin/render-all.php build/check
node scripts/check-seo.js build/check docs
```

## Админка

- Адрес: `/php/admin/`. Первый администратор или сброс пароля (пароль вводится в консоли; без SSH на хостинге — локально, затем залить `php/data/admin_users.json` по FTP):
  ```
  php php/bin/set-password.php <логин>
  ```
- Пароль: от 10 символов, буквы и цифры. Сменить свой пароль — страница «Parole».
- После 5 неверных паролей вход с этого IP блокируется на 15 минут; после 30 минут бездействия нужно войти снова.
- Удаление, публикация и выход — только кнопками (POST с CSRF). Флажок «Publicēts» снимает материал с сайта без удаления.
- Загруженные изображения проверяются по содержимому, уменьшаются до 1600 px, очищаются от EXIF и получают WebP-копию (нужно PHP-расширение GD; без него файл сохраняется как есть и админка предупреждает). Неиспользуемые загруженные файлы удаляются вместе с материалом; файлы из `img/` не трогаются.
- События входа и изменений пишутся в журнал ошибок PHP сервера с префиксом `[gehwol-admin]`.

Тесты: `composer test` (включает GD и exif для тестов изображений).
